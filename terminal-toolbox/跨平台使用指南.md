# ibox 跨平台使用指南（macOS + Windows）

> 适用范围：macOS（已装）+ Windows（本指南重点）。
> 配套文档：`ibox-使用说明.md`（全功能用法）、`tk-技术解读.md`（引擎原理）。
> 本指南只讲「怎么在 Windows 上装起来、和 macOS 共享命令卡」。

---

## 0. 一句话原理

工具箱是一套**纯 Python 标准库**写的小工具，数据源是普通 markdown。

- 核心引擎（路径 / ollama 调用 / 融合排序 / 剪贴板 / 按键读取）**已完整跨平台**；
- macOS 靠 `~/bin` 软链 + zsh 别名调用，Windows 靠 `.cmd` 包装器 + PowerShell 别名调用；
- 命令卡首次运行**自动从仓库内置副本初始化**到用户目录，零配置即用。

所以「在 Windows 上用」= 装 Python + 跑一次安装脚本，没有平台专属代码要改。

> **2026-09-14 起**：`hi`（系统信息）与 `gup`（git 同步）已用 Python 重写为 `ibox hi` / `ibox sync`，
> **Windows 上同样可用**（此前是 bash + macOS 专属命令，Windows 根本跑不了）。
> 同时修复了 Windows 上「浏览只能看一张卡」的按键读取问题。

## 1. Windows 安装（五步）

### 第 1 步：装 Python
到 https://www.python.org/downloads/ 下载 Windows 版安装包。
**关键**：安装界面务必勾选 **`Add python.exe to PATH`**（最底下那一项），然后「Install Now」。
验证：打开 PowerShell，输入 `python --version` 有版本号即成功。

### 第 2 步（可选，语义检索用）：装 ollama
到 https://ollama.com/download 下载 Windows 版，安装后它会自己后台跑 `ollama serve`。
首次用语义检索时，工具会提示你拉取嵌入模型：
```
ollama pull bge-m3            # 中文语义更佳（推荐）
# 或
ollama pull nomic-embed-text  # 轻量兜底
```
> 不装 ollama 也能用——只是退回纯本地匹配，跨语言 / 同义查询会弱一些。

### 第 3 步：拿到工具箱
方式 A（推荐，可同步更新）：
```
git clone https://github.com/OGGIoao/terminal-list
```
然后记住克隆下来的 `terminal-list/terminal-toolbox` 这个文件夹路径，例如
`C:\Users\你的名字\terminal-list\terminal-toolbox`。

方式 B：直接把 `terminal-toolbox` 文件夹拷到任意位置（如 `C:\Users\你\terminal-toolbox`）。

### 第 4 步：一键安装（加 PATH + 别名）
在 PowerShell 里 `cd` 到 `terminal-toolbox` 目录，执行：
```
.\install.ps1
```
它会自动：
1. 检查 Python（缺则提示去装）；
2. 把工具箱目录加入**用户 PATH**（持久化，重启终端生效）；
3. 在 PowerShell 配置文件写入别名块 `ibox` / `c` / `pycheat` / `tk`
   （首尾标记包裹：重复运行会**原地升级**，不会堆叠重复定义）。

> 若 PowerShell 报「禁止运行脚本」，先执行一次：
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`
> 再重跑 `.\install.ps1`。

### 第 5 步：开新的 PowerShell，开用
```
ibox                  # 开场屏：完整使用指南（记不住就敲它）
ibox how 查端口占用     # 人话搜命令
ibox find 部署报错      # 搜你自己的笔记 / 日志 / 提交
ibox add "改 ssh 端口"  # 记一条快记
ibox hi               # 我在哪台机器（Windows 也能用）
ibox sync             # 一键 git 同步
c 查端口占用            # c 是 ibox 的短别名，肌肉记忆不变
```

## 2. macOS（已装，简述）

你已经在用。复核一下软链与别名即可：
```bash
ln -s ~/terminal-toolbox/ibox ~/bin/ibox            # 已做
ln -s ~/terminal-toolbox/tk ~/bin/tk                # 已做（兼容旧名）
ln -s ~/terminal-toolbox/pycheat.py ~/bin/pycheat   # 已做（兼容旧名）
# ~/.cheat.zsh 里应有：alias c='ibox'
```
`ibox` / `tk` 在仓库内无 `.py` 后缀（专门给 macOS 软链用），Windows 端用 `runpy` 执行同一份文件，两端**共享同一源码**，不会漂移。

## 3. 让 Windows 与 macOS 共享同一份命令卡

命令卡数据源位置：
- macOS：`~/.config/cheat/cheatsheet.md`
- Windows：`C:\Users\你\.config\cheat\cheatsheet.md`

**想两边同步加过的卡**，任选一种：
- **同步盘法（推荐）**：把上面这个 `cheatsheet.md` 放进 OneDrive / iCloud Drive，让两边同步盘双向同步该文件；
- **软链法**：在一端把 `cheatsheet.md` 软链到同步盘里的同一份。

> 注意：仓库内置的 `cheatsheet.md` 是「出厂副本」，仅首次用来初始化；你日常编辑的是用户目录那份，不会污染 git 仓库。

个人数据（note / todo / clip 的 jsonl、向量缓存）也都在 `~/.config/cheat/` 下，同样可纳入同步盘实现跨机延续。

## 4. 命令速查（两端通用）

| 想做 | 怎么敲 |
|---|---|
| 看使用指南 | `ibox` |
| 人话搜命令 | `ibox how 你想干的事`（或 `c 你想干的事`） |
| 复制示例到剪贴板 | `ibox how -c 关键词` |
| 列全部卡 | `ibox how -l` |
| 记一条快记 | `ibox add "内容"` |
| 搜快记 | `ibox find 关键词` |
| 加任务 | `ibox add "内容" --in todo` |
| 看未完成任务 | `ibox find --in todo` |
| 完成任务 | `ibox done <id>`（id 见上一条输出） |
| 日志语义捞针 | `ibox find --in log "连接被拒绝" -p app.log` |
| git 提交语义搜 | `ibox find --in git "语义检索"` |
| 记录 / 搜剪贴板 | `ibox add --clip` / `ibox find --in clip` |
| 命令翻人话（需 chat 模型） | `ibox ask tar -xzf` |
| 长输出摘要（需 chat 模型） | `cat 长日志 \| ibox ask --sum` |
| 机器信息 | `ibox hi`（`-v` 看芯片 / 内存） |
| 一键 git 同步 | `ibox sync` |

> `ask` 需要本机有**对话模型**（bge-m3 / nomic 不能对话）：
> `ollama pull qwen2.5:0.5b`（轻量，练手够用）。

## 5. 排错

| 现象 | 原因 / 解决 |
|---|---|
| `ibox` 不是命令 | 没跑 install.ps1，或没「重开 PowerShell」。重跑第 4 步。 |
| `c` 不是命令 | 同上；`c` 是 install.ps1 写入的别名。 |
| `python` 不是命令 | 第 1 步没勾 Add to PATH。重装或手动把 Python 加进 PATH。 |
| 首次运行提示「已初始化命令卡…」 | 正常，首次从仓库副本初始化到用户目录，之后编辑用户目录那份。 |
| 翻页 / `q` 没反应 | 已修（2026-09-14）；拉最新代码即可（Windows 走 `msvcrt` 读键）。 |
| 语义检索没生效（跨语言查询不准） | ollama 没跑。PowerShell 里 `ollama serve`；或 `ollama list` 确认模型已拉。 |
| `ibox ask` 报缺模型 | 拉一个 chat 模型：`ollama pull qwen2.5:0.5b`。 |
| `ibox sync` 报不是 git 仓库 | 先 `cd` 到仓库根目录再跑。 |
| 想重装 / 换目录 | 把新目录加入 PATH（install.ps1 幂等可重跑），旧 PATH 条目手动删或忽略。 |

## 6. 文件清单（仓库 `terminal-toolbox/`）

| 文件 | 作用 | 平台 |
|---|---|---|
| `ibox` | **统一入口**：子命令分发 + 开场指南 + `hi` / `sync` | 跨平台 |
| `pycheat.py` | 命令卡引擎（检索 / 卡面渲染 / 交互浏览，被 ibox 复用） | 跨平台 |
| `tk` | 数据域层（note / log / git / clip / todo / explain / sum，被 ibox 复用） | 跨平台 |
| `tkcore.py` | 共享引擎（融合排序 + ollama 零依赖 + 向量缓存） | 跨平台 |
| `cheatsheet.md` | 命令卡数据源（出厂副本） | 跨平台 |
| `ibox.cmd` / `pycheat.cmd` / `tk.cmd` | Windows 入口包装器 | Windows |
| `install.ps1` | Windows 一键安装（PATH + 别名块） | Windows |
| `hi.sh` / `gup.sh` | 旧 bash 版（功能已被 `ibox hi` / `ibox sync` 取代，保留备查） | macOS / Linux |

> Windows 上统一用 `ibox` 即可：`hi` / `sync` 都已 Python 化，**不再有「Windows 用不了」的功能**。
