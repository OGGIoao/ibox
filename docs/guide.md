# 使用说明

先完成[README 的安装步骤](../README.md#第一次安装)，在 Windows PowerShell 输入 `ibox` 或 `python -m ibox`。

## 选工具和返回

启动后有一个 `>` 输入提示。按回车可打开工具列表。编号在列表和地图中一致。

| 编号 | 工具 | 命令 |
| --- | --- | --- |
| 1 | 查端口 | `/port` |
| 2 | 根系探测器 | `/roots` |
| 3 | 文件精灵 | `/file` |

在列表中输入「自启」「卸载」「指纹」可按用途筛选。用完工具会回到列表，并保留筛选词。输入 `/` 查看全部。

`/map` 按灯下世界的地表、地层、深层、核心介绍电脑，也能直接输入编号选工具。地图里的工具用完就回地图。列表或地图内直接回车，回到主输入区。`/exit` 退出 iBox。

## 查端口

端口号是程序等待连接时使用的编号。当前工具查询的是本机 TCP 监听，也就是哪些程序正在指定地址上等待建立连接。

可以从三个地方找要填的数字。

| 位置 | 例子 | 应该填什么 |
| --- | --- | --- |
| 浏览器地址栏 | 自己电脑上的页面是 `http://localhost:3000/` | `3000`，或粘贴整个地址 |
| 程序启动时的终端窗口 | 程序显示 `127.0.0.1:8080` | `8080` |
| 软件设置或报错 | 「端口 3000 已被占用」 | `3000` |

进入 `/port` 后按提示填写。也可以在 iBox 中直接问「谁在用 3000？」。结果先给程序名、监听地址和进程编号，选 **2 详情** 可展开说明和程序路径。

- **监听地址**是程序等连接的位置。`127.0.0.1` 和 `::1` 是本机回环地址。
- **进程编号（PID）**是 Windows 给一次正在运行的程序分配的编号。
- **程序文件位置**是本次能读取到的可执行文件路径。受权限或进程退出影响，有时读不到。

选 **3 重查** 可以在启动或关闭程序后再查一次。查不到 TCP 监听时，可核对数字并重试。单次空结果只能说明当时的查询情况。

## 根系探测器

进入 `/roots` 后，先选 **1 查软件**，输入软件名或厂商名，例如 `Python`、`wps`。采集可能需要几十秒，完成后浏览器会打开本机报告。

报告按系统位置整理卸载登记、自启项目、服务、计划任务、快捷方式等线索。**根**是软件留在电脑里的记录。**断根**是登记还在、指向的文件已找不到的记录。

报告里的归属判断依赖名字、安装路径和数字签名等证据。查看一条记录时，可以同时看它的原始位置和判断理由。只按名称匹配到的项目需要继续核对。

选 **2 保存或对比快照**，可以把某一时刻的系统记录保存下来。准备安装或卸载软件时，可依次保存「装之前」「装之后」「卸载后」，再对比两张或三张。快照记录的差异对应整个时间段的系统变化，可以结合自己的操作判断归属。

## 文件精灵

进入 `/file` 后，会出现 Windows 文件选择框。选一份文件，就能看到位置、字节大小、修改时间和内容指纹。

内容指纹使用 SHA-256 计算，适合核对副本。点击「对比另一个文件」，选另一份文件，会显示内容指纹是否相同。文件名或位置不同的两份副本也可以这样比。

「复制指纹」把当前文件的指纹放到剪贴板。「另存检查结果」会弹出保存窗口，由你选择位置和文件名。已有同名文件时，需要换个名字再保存。检查信息来自本次打开时的读取，文件后来变化时可以重新打开检查。

该入口在窗口内完成查看和对比。旧版留下的像素卡片目录存在时，会显示「管理旧卡片」，方便打开后整理。

## 结果和文件管理

根系探测器会读取软件相关的本机记录，并生成 HTML 报告或 JSON 快照。文件精灵会读取你选择的文件，并按需要另存文本结果。两件集成工具均在本机处理。

根系探测器默认输出目录为当前用户主目录下的 `.config/ibox/tools/root-probe/records/`。在工具菜单中选 **3 换目录**，粘贴一个现有文件夹，例如 `D:\iBox`。产物会放到它下面的 `iBox-根系记录` 文件夹，设置会在下次打开时沿用。

选 **4 管理保存的结果**，资源管理器会打开当前产物目录。选中用完的文件，按 Delete 删除。恢复默认位置时，在换目录提示里输入「默认」。更换设置只影响之后的保存和查看，先前的文件留在原位置。

可以设置环境变量 `IBOX_HOME` 更换 iBox 的配置根目录。该位置也存命令卡的最近查看状态、自定义卡和可选的向量缓存。

## 安装更新与卸载

如果 `ibox` 命令找不到，但 `python -m ibox` 能运行，可以继续用后者。从下面命令查到 Python 的用户命令目录，添加到 Windows 用户 Path 后再开终端，也能直接使用 `ibox`。

```powershell
python -c "import sysconfig; print(sysconfig.get_path('scripts', 'nt_user'))"
```

更新后在含 `pyproject.toml` 的源码文件夹重新安装。

```powershell
python -m pip install --user --force-reinstall .
```

使用安装时同一个 Python 卸载。

```powershell
python -m pip uninstall ibox
```

个人报告、快照和另存的文件由你管理，可在上面的目录中查看。
