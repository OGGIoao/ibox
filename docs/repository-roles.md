# 仓库分工

## 当前确认

2026-11-18，老李确认 iBox 作为数字文明的公开工具产出仓库。这里交付可在电脑上运行的工具、安装配置、使用说明、工程测试和源码拆解。当前先在自己的电脑完整体验，再准备推广。

个人系统学习文章服务作者自己的学习。数字文明仓库已有的 `learn/` 留在本机，并由 Git 忽略。作品使用者需要的操作、术语和实现说明随工具公开。

## 原数字文明仓库的整理建议

[数字文明](https://github.com/OGGIoao/digital-civilization) 继续承担灯下的世界观与故事制作。游戏和视频按实际制作节奏推进。建议按下面的职责组织。

| 位置 | 内容 |
| --- | --- |
| 世界观与设计文档 | 灯下的正史、角色、视觉语言和 ADR |
| 游戏原型与源码 | 已有主章灰盒、首岛独立试玩、各自的启动说明和验收 |
| 视频制作资料 | 分镜、剧本、旁白和生成脚本；成片随发布提供下载 |
| 进度与想法 | 当前阶段、验证证据、未实施的设计 |
| 本机学习目录 | 私人文章、实践与阅读疑问，继续在 Git 忽略范围内维护 |

现有 `outputs/` 已按游戏、独立试玩、视频分了目录，可以先补入口说明。只有目录名确实妨碍查找时，再成组迁移并修复引用。

数字文明现有的 `toys/` 是这些工具的起点。后续建议将持续维护的工具代码及其用法、原理和测试集中到 iBox，并在原位置保留迁移说明与链接。届时再确定旧右键版文件精灵是否继续随 iBox 单独分发。

以上涉及旧仓库文件移动的部分仍是整理建议。本次提交保存 iBox 当前的运行代码，旧仓库的游戏、视频、学习目录维持现有位置。
