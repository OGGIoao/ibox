# M2.3｜本机 DIY 反馈

老李在自行体验时提出端口指引、产物占盘、文件精灵用途和终端布局改进。状态为 `Review`，iBox 0.3.7 已构建并安装。

| 项 | 内容 |
| --- | --- |
| Goal | 新手知道去哪里找端口，能自主选择产物目录，并用文件精灵核对文件。 |
| Non-Goal | 系统文件清理、自动清空历史、重做独立右键玩具、公开分发。 |
| Deliverables | 端口输入指引及分色结果；根系保存目录设置及打开目录管理；原生文件检查弹窗。 |
| Technical Boundary | 沿用 iBox 与 Windows PowerShell。终端负责引导，使用 Windows 系统对话框完成文件选择和按需另存。保存位置单独记录，已有报告可回原目录查看。 |
| Exit Criteria | 实测本机地址输入、颜色与无色输出、非默认目录和打开目录、原生窗与文件对比、另存路径及原文件保持原样。 |

## 参考

- 查询于 2026-11-15。文件窗选择 Windows PowerShell 5.1 可加载的 [WinForms Form](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.form?view=netframework-4.8.1) 与 [SaveFileDialog](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.savefiledialog?view=netframework-4.8.1)，从安装包内固定入口调用。
- 老李要求参考 Claude Code 终端体验。对照官方截图中的单一强调色、空白和独立输入区，首页保留真实工具和一行四层索引，返回后直接出现输入提示。较长的说明分别由 `/map` 与端口查询的「详情」提供。 [Anthropic 终端截图](https://www.anthropic.com/news/enabling-claude-code-to-work-more-autonomously#enhanced-terminal-experience)
- 0.3.2 将工具清单放到 `/tools`，每件工具有可直接输入的命令。启动页借用数字文明世界观里 Echo 的菱形与光标，做成三行静态 ASCII 小向导。旁边说明用途，下面给一个提问范例和找工具的命令。形象依据见数字文明的 `docs/world/WORLD-BIBLE-v0.1.md`。

## 验证与 Review

- 26 项 Python 测试、56 张命令卡校验、文件精灵 12 项检查与根系探测器 14 项检查均通过。
- 在安装版的 Windows 伪终端里粘贴真实本机监听的 URL，查到正确 PID，并验证三种字段颜色、文件位置的颜色以及无色输出。
- 用安装版在 E 盘自选目录生成真实勘探报告，验证下次可读到保存位置，以及恢复默认后原报告保持原样。目录打开行为在回归测试中核对参数，文件删除由使用者在资源管理器选中后执行。
- 对真实 WinForms 窗体做离屏渲染，核对表单字段与按钮布局。用含中文及空格的测试文件验证相同与不同指纹、所选位置另存及拒绝覆盖原文件。鼠标操作系统文件选择器、剪贴板与资源管理器由老李继续试玩。
- 0.3.1 的 26 项回归全部通过。在 60 列 × 24 行的 Windows 伪终端验证单色强调和无色模式、真实端口查询、按需展开详情、返回输入提示，以及 `/map`、`/tools` 和 `/exit`。
- 0.3.2 的 26 项回归全部通过。在 56 列 × 24 行的 Windows 伪终端验证安装版的三行形象、按需展示工具、`/port` 粘贴本机地址查真实监听，以及 `/roots` 进入工具。文件精灵的斜杠命令通过入口测试。
- 0.3.3 的 26 项回归全部通过。核对了安装版首页的世界观介绍、工具用途与入口提示的顺序，并检查了 56 列以内的显示宽度。
- 0.3.4 的 26 项回归全部通过。在 56 列 × 24 行的 Windows 伪终端验证安装版的 `/map` 展示四组故事与真实机制，并从地图给出的 `/port` 命令追到真实本机监听。
- 0.3.5 的 27 项回归全部通过。安装版实测回车开工具列表、按名称和用途筛选、查端口后保留筛选、直接换到根系探测器和恢复全部列表。
- 0.3.6 的 27 项回归全部通过。安装版 `/map` 改为每层一句描述加对应工具，核对了文字顺序和窄终端显示宽度。
- 0.3.7 的 28 项回归全部通过。安装版实测从地图按编号查到真实监听，返回后继续进根系探测器，再回地图。文件精灵返回路径由入口测试覆盖。
