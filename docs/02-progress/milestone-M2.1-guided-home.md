# M2.1｜端口查询的新手首页

## 阶段边界

老李于 2026-11-15 确认按面向新手的标准继续构建。

| 项 | 内容 |
| --- | --- |
| Goal | 第一次打开 iBox 的人能直接提问或从常见问题进入本机查询，理解查到了谁。 |
| Non-Goal | 自启记录、资源监控、新的系统读取能力。 |
| Deliverables | Windows 首页与「灯下」ASCII 四层地图、常见端口问题输入与引导、同端口复查、结果与依据、一次结果动效。 |
| Technical Boundary | 复用已有 Windows 只读查询与 Python 标准库。保留直接查询和命令卡入口。 |
| Exit Criteria | 验证输入错误、真实监听、空结果、错误回退与返回。新手能独立选到入口、输入端口并说出结果。 |

当前状态为 `Review`。已完成实现、工程验证和本机安装，首次用户试玩待安排。详见 [源码拆解](../03-learning/milestone-M2.1-source-guide.md)。

## 交互参考

首页按数字文明世界观圣经的地表、地层、深层、核心顺序排列，借用风格 B 的终端字符表现。每层用一行介绍，并用不同的终端颜色、字符和层名区分。地图下方按启动、关闭、遇到端口报错三个场景引导查询，保留一个可照着输入的例子。参考本地 `digital-civilization/docs/world/WORLD-BIBLE-v0.1.md` 和 `digital-civilization/outputs/style-videos/src/style-terminal.js`。

沿用数字文明 ADR-007 的关系线，用一次动效把监听地址、进程编号和程序名连起来。结果先给结论，详细依据按需展开，参考 [Process Explorer 的选中对象与详情层次](https://learn.microsoft.com/en-us/sysinternals/downloads/process-explorer#introduction)。

## 验证与 Review

- `python -m unittest discover -s tests` 的 24 项全部通过，覆盖中文问题、有多个候选端口、错误输入、查询失败后重试、空结果、依据展开、退出和重定向。56 张命令卡通过格式检查。
- 从仓库外通过 Windows 伪终端运行已安装的 `ibox.exe`，完成入口选择、真实回环监听查询、PID 核对、打开依据、返回首页和退出。动效开启和关闭均通过，直接查询也返回相同 PID。
- 安装更新后，从首页输入「谁在用 <测试端口>？」查到真实回环监听和正确 PID。关闭监听后按「重查这个端口」，确认返回空结果，并走通第二个常见问题的输入引导。
- 加入四层地图后，24 项回归全部通过。安装版在 60 列 × 24 行的 Windows 伪终端中显示四层和输入提示，中文提问查到真实监听并能返回首页。
- 加入四层配色和三个场景后，24 项回归全部通过。在 60 列 × 24 行的 Windows 伪终端验证安装版的四种前景色、无色模式，以及从新增的报错场景进入真实端口查询。
- 剩余验收项是让一位第一次使用 iBox 的人独立完成查询，观察入口、输入和术语说明是否容易理解。
